# VANTIER — Luxury Real Estate

An ultra-luxury architectural real estate website engineered for high-performance visual storytelling, featuring a 4K GPU canvas sequence scrubber, seamless Lenis smooth scrolling, centered typographic flow, and an exclusive curated collection of sovereign international residences.

## Features
- **GPU Canvas Sequence Engine**: 270 HD frame sequence scrubber with instant initial load, zero loading screens, and offscreen ImageBitmap decoding.
- **Architectural Storytelling**: 6 synchronized real-time scene beat narrative cues (`01 / THE GROUNDS` to `06 / MASTER SANCTUARY`).
- **Dynamic Header System**: Transparent minimalist header with subtle dark border, complete fade-out during hero immersion, and sleek obsidian glass transition upon reaching the Private Estates Collection.
- **Private Estates Collection**: Curated luxury estates portfolio with interactive category filters, specifications, and modern responsive cards.
- **Ultra-Performance Architecture**: Native Gzip compression, WebP-optimized assets, deferred interaction preloading, and instant DOM interactivity (<150ms).

## Quick Start
To run locally:
```bash
node server.js
```
Or open `index.html` directly in any modern browser.
